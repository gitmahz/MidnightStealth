# Midnight Stealth

A simple stealth game made with Odin + Raylib Stack.

## Description

Midnight Stealth is a game where the player controls a house cat sneaking around a sleeping household at night.

The player must complete objectives while managing the amount of noise they create to avoid waking the household.

## Technology

- Odin
- Raylib
- Visual Studio Code

## Project Structure

- `src/` - Source code
- `assets/` - Game assets
- `data/` - Game data
- `docs/` - Documentation
